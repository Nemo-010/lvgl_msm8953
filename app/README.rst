Zephyr LVGL on Xiaomi Redmi Note 4 (MSM8953)
############################################

See the repository README. Build with::

    west build -b mido

The board, SoC and drivers are provided by this repository itself
(``BOARD_ROOT``/``SOC_ROOT``/``DTS_ROOT``/``ZEPHYR_EXTRA_MODULES`` are set in
``app/CMakeLists.txt``).
